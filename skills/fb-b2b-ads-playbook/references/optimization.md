# 诊断、止损与扩量

先校验数据，后解释差异。以下均是候选原因与实验路径，不是因果结论。

| 观察 | 核查 | 一个可控实验 |
| --- | --- | --- |
| 没有投放/花费很少 | 审核、账户/支付、排期、受众、预算下限、渠道连接 | 修复一个确认的配置问题后再观察 |
| CPM 上升 | 同市场时段竞价、受众规模、版位结构、样本变化 | 保持素材与链路，测试一个受众条件 |
| CTR(link) 下降 | 点击类型是否一致、素材疲劳、采购用途是否明确 | 同受众和预算测试新开场/视觉角度 |
| 点击多但询盘少 | 号码/页面是否可用、速度、文案与目的地一致、表单摩擦 | 测试一个资格问题或目的地步骤 |
| 平台结果便宜但合格少 | 去重、实际采购身份、MOQ/供货适配、已评估覆盖率、人工首响 | 测试明确买家身份的文案或一个资格问题 |
| 合格多但报价/成交少 | 报价速度、产品/物流适配、销售观察期、毛利与成交定义 | 修复一个销售跟进环节并等待队列成熟 |
| 频次升高且质量变差 | 同期触达、素材、季节性、样本规模 | 测试新素材，避免把频次单独当止损阈值 |

## 判断顺序

1. 配置/追踪故障、无法供货、违规或超过用户硬上限时先提出明确修复或暂停建议；获得具体授权才改真实账户。
2. 线索未评估、销售延迟或不同归因口径时，补数据或继续观察；未评估不能计为不合格。
3. 观察期成熟后，以用户目标与历史基线评估 CPQL、报价或获客成本。质量未达标时先选漏斗环节，不把所有问题都归给受众。
4. 当 CPQL、销售处理能力和质量持续可接受时，提出有上限的扩量实验，明确新日预算、总额、观察条件和回退条件。没有确定基线时只建议受控测试，不承诺盈利。

## 样本与成本

小样本的“0 成交/1 个合格”不能支撑市场定论；描述差异与不确定性。未随机分流的广告组/国家比较是观察性证据。多个变量或平台自动分配同时变化时不得宣称某一变量造成效果。

如果估算成本可承受范围：获客花费上限 ≤ 单个新客户可贡献利润 × 用户选择的可用于获客比例；可承受 CPQL = 获客花费上限 × 合格线索到新客户的成熟队列转化率。这是自定义经营预算模型，须披露履约/退货/重复采购与销售成本范围，不混淆毛收入与利润，不使用未成熟转化率。未知利润或成交率则不算具体止损价。

不承诺某预算增幅不会触发学习变化。按当前官方资料和账户状态核实重大修改；减少无必要反复编辑，记录所有改动。不得为了“满足学习期”强行购买无效线索或花完预算。

用 `output-template.md` 的实验记录注明主变量、指标、观察期、质量定义、预算与成功/停止条件。成功条件由业务目标或基线决定，平台默认结果数量不能替代业务结果。
