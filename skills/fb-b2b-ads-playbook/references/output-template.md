# 输出模板

按主流程选用模板；省略不适用字段。用户要「全部放代码框」时将所需配置与文案合并；来源和核验状态依然可辨识。

## A. 完整产品方案

1. **事实与市场测试**：已确认/未知/假设；候选国家及理由/来源/阻碍；优先市场。
2. **策略与预算**：目标→转化位置→绩效目标；实际账户待确认项；币种、日总预算、广告组分配、天数、总上限；主变量及成功/停止条件。
3. **可复制配置与素材**：用下面模板；目标/按钮属于配置说明，正文/标题才是实际填写文案。占位符未补齐前标明草稿。
4. **操作与复盘**：基于当前截图写层级和步骤；上线前预览/渠道/隐私/预算检查；何时检查什么数据、由谁跟进与记录。

## B. 截图选择与填写

选择问题：选择、点击、原因，通常三行；不清楚时标明缺失字段而不猜按钮。填写问题：按截图字段顺序给独立代码框，附中文解释和必须核对的占位符。

## C. 数据复盘

- 结论：暂停核查 / 继续观察 / 进行某实验 / 在具体授权下调整。
- 口径与可靠性：数据来源、期间、币种、层级、归因、CRM 对齐、已评估覆盖率、未成熟线索。
- 指标表：花费、平台结果、去重线索、已评估、合格、CPQL、报价/成交，缺失用「未知」；零分母用「不可计算」。
- 诊断表：观察证据、候选原因、排查/实验、预算上限、成功/停止条件、负责人。
- 下一次复盘：明确日期或触发条件；记录需要补的数据。没有统计证据时不标注显著胜出。
