# 平台与市场核验

## 查询流程

涉及当前目标、按钮、绩效选项、Advantage+、定向/排除、预算与学习、消息模板、数据处理、广告政策、关税或市场推荐时，联网读取一手资料。平台功能优先 Meta 官方；监管优先目的国政府；统计优先官方贸易数据。技术问题只使用官方文档或原始资料。

记录标题、URL、发布日期/更新时间、核验日期、支持的具体结论和账户适用限制。搜索摘要不等于完整核实。帮助中心登录墙、网络失败或无可靠来源时标明「未核实」，用用户截图确认实际选项，不以第三方传闻替代规则。

## 易过期项

不要预设 Leads/Messaging 的完整路径、Higher Intent 是否存在、详细定向排除可用、年龄/性别是否硬限制、位置类型可选、每日预算是否硬花费上限或自动版位包含哪些渠道。预算上限与实际支出机制需当前资料核实；日预算 × 天数只是计划金额，不是平台强制封顶。

未经检查不生成特定监管认证、消息发送窗口或数量规则。区分 WhatsApp Business app、Business Platform/API 与 Ads Manager 中的模板；广告聊天设置不能代替 API 主动消息审批。实际自动化须根据可用工具、明确授权、用户选择与当前规则执行。
